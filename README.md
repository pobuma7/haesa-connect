# HAESA CONNECT

Static website for HAESA CONNECT — community platform for History, Archaeology
and Economics students and alumni from African institutions.

## Structure
- `index.html` — Home
- `opportunities.html` — Scholarships, fellowships & internships
- `articles.html` — Articles, write-ups & media
- `about.html` — About, vision & mission
- `admin.html` — Local tool for generating new article entries (drag & drop)
- `data.js` — Edit this file to add opportunities or articles
- `assets/` — Logo and article images

## Editing content
Open `data.js` in any text editor and edit the `OPPORTUNITIES` or `ARTICLES`
arrays directly, or use `admin.html` to generate a new article entry.

## Deploying
This is a static site — no build step. It can be hosted as-is on GitHub Pages,
Cloudflare Pages, Netlify, or any static host.
